# Unified Wind v0.4.0

version `0.4.0` of unified wind is out now on Modrinth! the update is mostly geared for mod devs, as it allows mods to make their wind behavior be the shared behavior!

check it out [here](https://modrinth.com/mod/unified-wind/version/0.4.0)!

the new API code is outlined on the mod's [docs](https://github.com/tmaster-terrarian/unified-wind/wiki/Guide-for-mod-developers%3A-how-to-add-Unified-Wind-support-to-your-mod! "GitHub wiki").

this is a rather large milestone for the mod, as it allows others with much cooler wind code to apply their wind to every mod that is supported by unified wind, which should vastly improve the mod when it comes to customization! there's still some work to be done, but things are going well so far.
